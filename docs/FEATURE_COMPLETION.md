# Release-candidate implementation and evidence

Feature-completion owner direction: 2026-10-16. Current phase (2026-10-17): [real-phone debugging and stabilization](STABILIZATION.md); the implemented scope below is the baseline, not a request for continued broad expansion. Romania-first local catalogue approved. No backend, account, paid API, billing key or recurring service.

## Supported behavior — current rc4 policy

- Normal retains its existing channel and lifecycle actions. Silent defaults to low importance with no audio/vibration and uses Done / Next time; dismissal is Next time. Urgent uses a distinct high-importance channel and requests ongoing presentation; it does not configure a stronger custom tone/vibration than Normal. Legacy timed Snooze is Alarm-only. Android 14+ permits dismissal; Urgent now schedules one inexact five-minute re-alert per swipe until explicit Done/Next time. Other intensities retain swipe-to-Next-time.
- Alarm is temporarily hidden from new choices; only existing Alarm reminders retain this implementation. Explicit conversion to Urgent is offered without silently changing saved rows. Android notification service receives an alarm-audio channel, strong vibration pattern and `FLAG_INSISTENT`. Stop silences the occurrence while retaining Done/Snooze; Done completes; Snooze persists a ten-minute deadline, schedules WorkManager and increments the occurrence token when due. Retries, duplicates and stale actions preserve generation/occurrence guards. Reboot restores already-delivered alerts quietly. Snooze is inexact and can be delayed by Android.
- Supported Alarm fallback: prominent notification with actions. Sound, vibration, DND, channel settings and OEM/OS behavior control alerting. Opening the notification panel can end repeating audio. The normal VIBRATE permission is declared for alert vibration; there is no extra runtime prompt. No background audio service, exact alarm permission or full-screen permission is requested. Full-screen auto-grant is reserved for core alarm/call apps; Ariciu is a location-reminder app. It does not promise or attempt full-screen background launch.
- My location requests only foreground permission on explicit use, accepts approximate positioning for the map, bounds cached fixes to 30 seconds, times out in 20 seconds and cancels requests with the screen coroutine. Background precise location remains a separate delivery setup step. Permission denial, disabled location and unavailable positioning explain alternatives.
- Search uses the bundled OSM derivative only. Accent-insensitive town, shop and known shop-address search runs locally. No street/house address completeness or worldwide coverage is claimed. Catalogue source timestamp: 2026-10-15T20:21:00Z; rebuilt 2026-10-17 from the same source. Includes 26,065 rows (231 malls added on 17 October; original 25,834 rows unchanged) and seven chains. The ODbL derivative, licence URI, provenance and regeneration script are shipped; no OSM user metadata is included.
- Chain reminders select up to 40 listed stores within 25 km of the chosen pin for new/explicitly refreshed snapshots. A chain is the union of these store areas: overlapping stores count as one visit; Once and Done apply to the whole reminder; Every visit requires leaving the union before another occurrence. Per-store positions/timestamps persist independently. Missed exits can conservatively delay rearming. Change the pin and refresh the selected stores when travelling; the app does not continuously follow you or claim to monitor every store in Romania. Catalogue updates ship with app updates; refreshing is explicit.
- Geofence allocation distributes capacity across reminders in deterministic rounds, capped at 100 actual areas. Partial chain monitoring is shown explicitly. Editing/refreshing replaces the generation; the registration ledger removes obsolete areas and recovers interrupted operations. Completion removes every store area.
- Offline maps use MapLibre Native's existing offline database. User-selected approximately 4×4 km packs cover zoom 10–14 for the selected theme. Up to three packs, one download at a time; pause/resume/delete and resource-byte use are shown in Settings. Downloads pause when leaving their screen or backgrounding Ariciu, and after 90 seconds with an explicit Resume option. Partial downloads persist and resume explicitly. Region downloads use the matching OpenFreeMap hosted style, whose tile/font/sprite resources are shared with the bundled display styles; asset:// is not used as a native download definition. Both display styles are bundled with their licences, and attribution remains visible. Download requests share four concurrent connections and an identifying User-Agent. Application budgets use a 45 MB HTTP cap and 2,500 `.pbf` response cap per active session (including glyph requests), with Native progress pause thresholds of 40 MB/2,000 tiles. On resume, byte count initializes from stored resource bytes while response count resets; this is not a proved lifetime cumulative traffic cap across retries/cache/resumes. Large/busy areas fail visibly. See the [source audit](STABILIZATION_AUDIT.md) for unreproduced lifecycle/accounting risks. Native MapLibre's Mapbox-only tile limiter is not relied upon for OpenFreeMap.
- Offline maps do not guarantee offline Play Services positioning. Only saved regions/themes/detail levels are protected; unvisited areas, overview/detail outside the pack and map-service updates can require connectivity.

## Current official restrictions and zero-cost evidence (checked 2026-10-16)

- [OpenFreeMap terms](https://openfreemap.org/tos/): free public service; explicit offline use up to 3,000 tiles or 50 MB per download, up to four concurrent requests and a unique app User-Agent. No key/account/billing. No availability or future-terms guarantee. Map requests disclose IP/area to the provider/CDN; search does not.
- [MapLibre Native offline API](https://maplibre.org/maplibre-native/android/api/-map-libre%20-native%20-android/org.maplibre.android.offline/index.html): supported region definitions/status/deletion. Existing MapLibre runtime retained.
- [Geofabrik free downloads](https://www.geofabrik.de/en/data/download.html), [OSM copyright](https://www.openstreetmap.org/copyright), [ODbL](https://opendatacommons.org/licenses/odbl/1-0/): legally reusable local catalogue, attribution/share-alike derivative provided. Raw regional extract is a build-time download, not an app endpoint. No public Nominatim/Overpass query service is used.
- [OkHttp 4.12 licence](https://raw.githubusercontent.com/square/okhttp/parent-4.12.0/LICENSE.txt): Apache 2.0, local HTTP client. Same version already present transitively through MapLibre is now a direct compile dependency to configure concurrency, User-Agent and byte budgets. No version upgrade, new remote service or billing.
- [PyOsmium](https://osmcode.org/pyosmium/): BSD-2-Clause development-only parser installed in a temporary virtual environment. Not an app dependency or required runtime service.
- [Vibration permission](https://developer.android.com/reference/android/Manifest.permission#VIBRATE) and [notification vibration](https://developer.android.com/reference/android/app/Notification#DEFAULT_VIBRATE): normal install-time permission, with actual vibration controlled by the channel/device.
- [Notification flags](https://developer.android.com/reference/android/app/Notification), [Android 14 ongoing dismissal](https://developer.android.com/about/versions/14/behavior-changes-all), [full-screen/FGS Play policy](https://support.google.com/googleplay/android-developer/answer/13392821), [Android 17 audio hardening](https://developer.android.com/about/versions/17/behavior-changes-17): supported system notification audio rather than app playback or launch workarounds. No claim that channels/ongoing requests override the user or OS.
- [CurrentLocationRequest](https://developers.google.com/android/reference/com/google/android/gms/location/CurrentLocationRequest): existing royalty-free Play Services SDK; no Google Maps Platform geocoder, Places or billed API is introduced.

OpenFreeMap terms (dated 2026-10-14) were rechecked on 2026-10-17 and retain the quoted download allowance. Other platform reviews above retain their 2026-10-16 review date; no permission/background behavior was changed during this documentation task.
